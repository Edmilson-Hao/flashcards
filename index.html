Como Funciona

🚀 O que é este app?

Este é um sistema de Flashcards Inteligentes. Ele utiliza o método de Repetição Espaçada para garantir que você memorize vocabulário ou conceitos de forma eficiente, revisando apenas na hora certa.

🧠 O Algoritmo (SRS)

O sistema gerencia quando você deve rever cada palavra:

  • Acertou? A palavra sobe de nível e a próxima revisão será agendada para uma data mais distante (amanhã, depois 3 dias, 7 dias...).
  • Errou? A palavra volta para o nível zero e deve ser revisada novamente hoje ou amanhã para fixação.

📚 Como usar?

  1. Adicionar: Cadastre palavras novas com tradução e exemplos.
  2. Revisar: O botão "Revisar" mostrará apenas o que venceu hoje. Tente acertar a tradução!
  3. Forçar Revisão: Se não houver nada pendente, você pode "Forçar" uma revisão para estudar o baralho todo.
  4. Biblioteca: Use para pesquisar palavras, ver seu progresso ou excluir itens errados.
